# Raíces Vivas · Prototipo 3D

Prototipo interactivo del espacio sensorial **Raíces Vivas** (Grupo 4 · Toulouse Lautrec), ubicado en el primer piso de la sede Javier Prado.

- Vista exterior del edificio y botón **Ingresar**.
- Estaciones: Panel audiovisual, Mapa interactivo, Costa, Sierra, Selva y Audio.
- Modos Orbitar y Caminar, recorrido guiado, luz de día y de tarde.

Abre `index.html` en el navegador o visita la página publicada con GitHub Pages.
